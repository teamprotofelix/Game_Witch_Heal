# 마녀의 여행: 작은 행복의 길 (Witch's Journey)

고화질 배경과 개별 추출된 마녀 스프라이트를 사용하는 **힐링 플랫포머**입니다. 백엔드·외부 CDN·웹폰트·API 키 없이 GitHub Pages에서 실행되는 정적 HTML/CSS/JS 게임이며 PWA 오프라인 설치를 지원하도록 구성했습니다.

## 기존판과 달라진 점

- **깨끗한 스프라이트**: 8×4 격자로 무작정 자르지 않고 원본 투명 PNG의 연결 영역을 식별하여 독립된 캐릭터만 추출했습니다. 깨진 포즈는 제외했습니다. 24개 완전 포즈를 WebP로 렌더링합니다.
- **게임 플레이**: 통나무·물웅덩이·가시덤불을 점프. 피격 시 게임 오버가 아니라 부드럽게 후퇴하며 다시 시도합니다. 성공 시 별가루와 점수 획득.
- **힐링 목표**: 풍경마다 꽃/아이템 4개, 동물 친구 2명, 성공적인 점프 2회, 마법 정원 활성화 1회를 달성하면 출구 랜턴이 열립니다. 네 장소를 모두 탐험하면 엔딩이 나옵니다.
- **부드러운 이동**: 관성이 적절히 보정된 가속/감속, 탭 이동, 모바일 누름 방향키, PC WASD·방향키. 부드러운 카메라 추적. 불필요한 전투·죽음·격렬한 이펙트 없음.
- **고화질 배경**: 숲/호수/달빛 정원/해안 풍경을 1920×1080 WebP로 제작·톤 보정했고, 전경은 투명도가 있는 산책로로 표현합니다.
- **산책 일기**: 수집품, 만난 친구, 소소한 추억, 행복 별가루, 점수, 점프 기록 표시. 자동 저장과 이어하기.

## 조작

| 기기 | 이동 | 점프 | 마법 | 기록 | 일시정지 |
| --- | --- | --- | --- | --- | --- |
| 스마트폰 | 화면을 탭·드래그 또는 ◀ ▶ 누르기 | ↥ 점프 | ✦ 마법 | 📖 기록 | Ⅱ |
| PC | 마우스 클릭 위치로 걷기 또는 ← → / A D | Space / ↑ / W | F | J | Esc |

장애물 직전에 점프하면 평소보다 높이 뛰어오르며 지나갈 수 있습니다. 마법 정원은 세 번째 장애물 이전 구간에 있습니다. 적을 공격하는 기능은 없습니다.

## 호스팅

1. ZIP을 풀면 **루트에 `index.html`**이 있고 `assets/` 등 파일이 나옵니다. 그 구조 그대로 public GitHub 저장소 루트에 업로드합니다.
2. Settings → Pages → Deploy from a branch → `main` / `/(root)`를 선택합니다.
3. GitHub Pages의 HTTPS 주소에서 접속하면 PWA 설치 및 오프라인 캐시가 지원됩니다. `file://`로 직접 열면 서비스워커는 사용할 수 없습니다.
4. 이전 버전을 설치한 경우 한 번 온라인 접속하여 서비스워커가 업데이트되도록 합니다.

브라우저 저장소(localStorage)만 사용하며 계정·서버 데이터 전송이 없습니다. PWA 표준 아이콘 두 개만 PNG이고 게임 이미지와 스프라이트는 전부 WebP입니다.

## 검증

Chromium 인메모리 모의 환경에서 데스크톱 1280×820, 모바일 세로 390×844, 모바일 가로 844×390에서 54개 게임 이미지 로드, UI 조작, 점프 및 보상, 마법 활성화, 기록, 일시정지·재개, 다음 스테이지 진행을 확인했습니다. 실제 GitHub Pages 실배포와 Android/iOS 설치·오프라인 전환은 아직 검증하지 않았습니다.
